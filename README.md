# Indicador Global de Divisas 🌍🧮

Proyecto full-stack para consultar cotizaciones internacionales en tiempo real frente al peso argentino (ARS) y operar con un **conversor universal** que permite cruzar libremente cualquier par de divisas.

## 🚀 Características Principales
- **Divisas Soportadas**: Dólar Oficial (USD), Euro (EUR), Real Brasileño (BRL), Yuan Chino (CNY), Naira Nigeriana (NGN), Libra Esterlina (GBP), Yen Japonés (JPY) y Peso Argentino (ARS).
- **Conversor Universal Interactivo**: Permite seleccionar tanto la moneda de origen como la de destino de forma libre, además de interactuar haciendo clic directamente en las tarjetas de cotización.
- **Interfaz Web Moderna**: Diseño responsivo y compacto en modo oscuro utilizando CSS Grid y Flexbox.
- **Múltiples APIs REST**: Consumo en tiempo real de **DolarAPI** y **ExchangeRate-API**.
- **Versión de Consola (Python)**: Script en Python 3 para consultas rápidas desde la terminal.
- **Despliegue Continuo**: Publicado en vivo mediante GitHub Pages.
