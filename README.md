# Indicador Dólar Argentina 💵

Script en Python que consume la API REST de DolarAPI para consultar y presentar las cotizaciones del dólar en Argentina en tiempo real por consola.

## 🚀 Características
- Consumo de API REST sin librerías externas (utilizando módulos estándar `urllib` y `json`).
- Formateo dinámico en consola para una lectura clara.
- Manejo de excepciones ante fallos de red.

## 🛠️ Tecnologías
- **Python 3**
- **Git & GitHub**

## 💻 Ejecución
```bash
python main.py
