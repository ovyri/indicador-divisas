# Indicador Global de Divisas 🌍🧮

Panel web y de consola para consultar cotizaciones internacionales en tiempo real frente al peso argentino (ARS) y operar con un conversor universal.

## 🚀 Características
- Cotizaciones en tiempo real de Dólar, Euro, Real, Yuan, Naira, Libra y Yen.
- Conversor universal interactivo.
- Versión en consola (Python 3).
- Desplegado en GitHub Pages.
