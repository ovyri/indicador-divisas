# Indicador Dólar Argentina 💵🌐

Proyecto full-stack/CLI para consultar y visualizar las cotizaciones del dólar en Argentina en tiempo real mediante el consumo de la API REST de DolarAPI.

## 🚀 Características
- **Interfaz Web**: Diseño responsivo con soporte para modo oscuro usando HTML5, CSS3 y JavaScript puro (`fetch` API).
- **Consola (Python)**: Script en Python 3 para consultar las cotizaciones directamente desde la terminal (`urllib` y `json`).
- **Deploy Automático**: Publicado en GitHub Pages para acceso en vivo.

## 🛠️ Tecnologías
- **Python 3**
- **JavaScript (ES6+)**
- **HTML5 & CSS3**
- **Git & GitHub Pages**
